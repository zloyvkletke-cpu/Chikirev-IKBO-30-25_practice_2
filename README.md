# NuGet Dependency Graph Visualizer

## 1. Общее описание
Инструмент командной строки для анализа и визуализации графа транзитивных зависимостей пакетов .NET (NuGet). 
Программа получает данные напрямую через NuGet V3 HTTP API, строит граф зависимостей с помощью алгоритма BFS и генерирует визуализацию с помощью языка диаграмм Mermaid.

### Структура проекта
```text
├── src/                  # Исходный код
│   ├── main.py           # Точка входа
│   ├── cli.py            # Парсинг аргументов командной строки
│   ├── fetcher.py        # Работа с NuGet API и локальными файлами
│   ├── graph.py          # Алгоритмы BFS и топологической сортировки
│   └── visualizer.py     # Генерация Mermaid и вызов CLI
├── tests/                # Тесты и тестовые данные
│   └── test_data.json    # Тестовый граф с циклом
├── Makefile              # Утилиты для запуска
├── requirements.txt      # Зависимости Python (стандартная библиотека)
└── mermaid_config.json   # Конфигурация для рендеринга больших графов
```

## 2. Описание всех функций и настроек
Программа поддерживает следующие флаги командной строки:

* `-p, --package` — Имя анализируемого пакета (обязательный параметр).
* `-u, --url` — URL-адрес репозитория NuGet или путь к локальному тестовому JSON-файлу.
* `-t, --test-mode` — Включает тестовый режим (чтение графа из локального файла).
* `-v, --version` — Версия пакета (например, `13.0.1`).
* `-o, --output` — Имя сгенерированного файла с изображением (по умолчанию `graph.png`).
* `-d, --depth` — Максимальная глубина анализа зависимостей (по умолчанию `5`).
* `-f, --filter` — Подстрока для фильтрации (пакеты, содержащие эту подстроку, игнорируются).
* `--stage` — Номер выполняемого этапа работы (от `1` до `5`, по умолчанию `5`).

## 3. Описание команд для сборки проекта и запуска тестов

### Предварительные требования
* Python 3.9+
* Node.js и npm (необходимы для рендеринга PNG через `@mermaid-js/mermaid-cli`)

### Установка
1. Установите Python-зависимости (проект использует только стандартную библиотеку, файл нужен для структуры):
```bash
pip install -r requirements.txt
```
2. Установите Mermaid CLI глобально (или используйте `npx`, который скачает его автоматически при первом запуске):
```bash
npm install -g @mermaid-js/mermaid-cli
```

### Запуск тестов
```bash
python -m unittest discover -s tests -v
```
Или через Makefile:
```bash
make test
```

## 4. Примеры использования

**Этап 1 (Вывод конфигурации в формате ключ-значение):**
```bash
python src/main.py -p Newtonsoft.Json -v 13.0.1 --stage 1
```

**Этап 2 (Получение и вывод прямых зависимостей реального пакета):**
```bash
python src/main.py -p Newtonsoft.Json -v 13.0.1 --stage 2
```

**Этап 3 и 4 (Построение графа и порядок загрузки в тестовом режиме):**
*(Пример с ограничением глубины до 2 и фильтрацией пакетов с буквой "G")*
```bash
python src/main.py -p A -u tests/test_data.json -t -d 2 -f "G" --stage 4
```

**Этап 5 (Визуализация в PNG):**
```bash
python src/main.py -p MediatR -v 12.2.0 --stage 5 -o mediatr_graph.png
```

### Демонстрационные команды через Makefile
* `make demo-real` — запускает анализ реального пакета `Newtonsoft.Json` и генерирует PNG с глубиной 2.
* `make demo-real-neb` — запускает анализ реального пакета `Newtonsoft.Json` и генерирует PNG с глубиной 1.
* `make demo-test` — запускает тестовый режим с фильтрацией и глубиной.
* `make clean` — удаляет сгенерированные файлы `.png` и `.mmd`.
